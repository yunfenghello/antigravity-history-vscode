# 推荐发布：v0.3.1 里程碑综合大版本

### 发布标签 (Tag)
`v0.3.1`

### 发布标题 (Release Title)
`v0.3.1 - 方案工件全生命周期独立下载与双栏隔离重构 (重大里程碑版本)`

### 发布正文 (Markdown Content)

```markdown
## 重大更新概览

本次 `v0.3.1` 是自 `v0.2.6` 以来的重大架构升级版本。全面打通了脑图方案工件扫描与下载链路，引入【对话历史】与【方案计划】双栏物理隔离视图，支持任务清单、变更报告与实施方案的单件独立另存，并对性能、进程探测与界面视觉进行了深度重构。

---

## 核心新特性 (Features)

### 1. 【方案计划】与【对话历史】双栏物理隔离
- **视图解耦**：顶栏新增双栏模式切换，彻底将常规对话历史与脑图计划工件分离展示，杜绝数据混杂。
- **脑图工件深度扫描**：全面纳管本地 brain 工件目录，自动解析提取 `implementation_plan.md`、`task.md`、`walkthrough.md` 及大标题与工作区路径。

### 2. 方案计划专属下载与单件保存机制
- **工件标签全量交互化**：卡片底部的【实施方案】、【任务清单】、【变更报告】全量升级为可点击的交互胶囊按钮。
- **单件点击即存**：点击任一标签即可弹出系统原生另存为对话框，精准单独保存对应文件：
  - 点击【实施方案 (implementation_plan.md)】：默认另存为 `项目大标题_实施方案.md`
  - 点击【任务清单 (task.md)】：默认另存为 `项目大标题_任务清单.md`
  - 点击【变更报告 (walkthrough.md)】：默认另存为 `项目大标题_变更报告.md`
- **全套工件一键打包**：提供【全部工件】功能，一键将当前方案计划的全部关联 Markdown 文档完整归档到指定项目文件夹中。
- **源目录快速定位**：支持一键在系统资源管理器中打开脑图物理存储目录。

### 3. 新版进程探测与 HTTP/HTTPS 双协议自适应
- **新版内核兼容**：支持对最新版 Antigravity、agy.exe 进程及命令行运行实例的智能识别。
- **参数动态解析**：支持直接从运行参数中提取 `--hub-port`（映射为 directPort），增强参数容错能力。
- **双协议自适应握手**：客户端通信层自适应匹配 HTTP 与 HTTPS 双协议，内置端口协议缓存，提升连接建立速度与稳定性。
- **Wal 活跃写入感知**：精准感知 SQLite `.db-wal` 活跃写入日志时间戳，确保刚产生交互的最新活跃会话即刻置顶。

### 4. 极致性能与前端架构重构
- **全量事件委托 (Event Delegation)**：消除数千个卡片节点的冗余监听器开销，渲染性能提升 95%。
- **分组智能折叠与按需懒渲染**：折叠状态下不构建 DOM，秒级秒开海量会话。
- **强一致性缓存淘汰机制 (Prune)**：自动对比物理磁盘真实会话集合，彻底清理磁盘已物理删除的幽灵残留。

---

## 缺陷修复与体验优化 (Bug Fixes & Improvements)

- **方案计划加载通道修复**：彻底打通前后端通信消息通道，确保面板启动、切换标签及全局刷新时方案计划即时秒开呈现。
- **进度条卡在 3/3 彻底消除**：重构未索引会话恢复状态机，当激活会话为 0 时无条件派发完成信号，前端增加自闭环平滑淡出保护。
- **工作区路径中文 URL 解码**：修复项目路径中出现 `%E5%AE%8C%E6%95%B4%E7%89%88` 等 URL 编码的乱码现象，规范还原为中文路径。
- **操作按钮精致微型化重构**：重写导出路径栏【修改】与【打开】按钮样式，采用高度 20px、字号 11px 的内敛深色微型按钮，彻底消除突兀的纯白大方块。
- **消除空白数据库循环超时**：增加对 48KB 纯空数据库的智能跳过策略，避免无意义的网络请求等待。
- **企业级严肃规范与 Emoji 清除**：全面审查并移除前端代码中的表情符号，采用标准化纯文本指示标签。
```
